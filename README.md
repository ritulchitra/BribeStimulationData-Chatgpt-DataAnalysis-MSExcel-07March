# 🕵️ Bribe Data Analysis Project (Simulated Dataset - Excel Dashboard)

This project presents a data analysis of a **simulated bribery dataset**, which was created with the help of **ChatGPT**. The goal was to simulate real-world bribery patterns, clean and prepare the data, and develop a comprehensive and interactive Excel dashboard for insights.

## 📌 Project Overview

The dataset was artificially generated to mimic patterns commonly found in bribery cases—such as departments involved, amounts, regions, and officer designations. After creating and refining the data, a detailed Excel dashboard was developed using slicers, PivotTables, and charts.

## 🎯 Objectives

- Create a simulated bribery dataset with realistic structure.
- Clean and prepare the data for analysis.
- Develop an interactive Excel dashboard to explore key insights.
- Visualize department-wise bribe amounts, officer trends, and regional hotspots.

## 📂 Files Included
- `bribe_dashboard.xlsx` – Final Excel dashboard with interactivity.
- `README.md` – Project documentation (this file).

## 🛠 Tools & Skills Used

- **Microsoft Excel**
  - Data cleaning & transformation
  - PivotTables and PivotCharts
  - Slicers for filtering

## 💡 Key Insights

- Total bribe amounts by department and officer.
- State-wise and region-wise bribery distribution.
- Identification of high-risk zones or repeated patterns.
- Bribe Trends and its relation with exams.
- Age groups and their trends.
